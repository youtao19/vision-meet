# 总体技术架构

## 页面目标

为 PPT“总体技术架构”页生成一张 16:9 参考信息图，说明四个核心功能如何展示、使用什么技术、如何实现。

## 核心功能展示

1. 数据处理 / 岗位画像
   - 展示：任务进度、阶段时间线、岗位画像列表、漫画化岗位画像。
   - 技术：Vue3 + TypeScript、任务流水线、Pi Agent、PostgreSQL。
   - 实现：岗位数据导入后进行清洗归一，压缩为统计摘要，调用 Pi Agent 生成岗位画像，并写入画像数据表。

2. 学生画像
   - 展示：简历解析结果、能力标签、技能结构、画像维度。
   - 技术：Express + TypeScript、结构化接口、学生画像仓储、Fetch API。
   - 实现：上传或录入学生信息后，后端统一转换为学生画像字段，前端展示能力标签和画像维度。

3. 路径图谱
   - 展示：岗位节点、晋升路径、转岗路径、技能差距、推荐路线。
   - 技术：Neo4j、图谱查询、路径推荐、岗位画像关系建模。
   - 实现：基于岗位画像生成岗位节点和关系边，通过图谱查询返回职业发展路径。

4. 职业报告
   - 展示：匹配结论、能力短板、行动建议、报告导出。
   - 技术：OpenAPI / Contracts、报告服务、结构化结果、前端报告页面。
   - 实现：聚合学生画像、岗位画像、匹配结果和路径图谱，生成可展示和可导出的职业报告。

## 技术能力层

- Vue3 + TypeScript 前端展示。
- Express + TypeScript 后端服务。
- Pi Agent 智能生成岗位画像。
- OpenAPI / Contracts 统一接口契约。
- PostgreSQL 存储岗位、画像、匹配与报告数据。
- Neo4j 支撑职业路径图谱。
- 任务流水线 + 失败重试保障长任务稳定运行。

## 数据链路

原始岗位数据 → 清洗归一 → Agent 生成岗位画像 → 学生画像匹配 → 路径图谱推理 → 职业报告生成。

## 底部总结

以统一契约连接前后端，以 Agent 生成能力沉淀岗位画像，以图数据库支撑路径推理，最终形成可展示、可追踪、可导出的职业规划结果。
