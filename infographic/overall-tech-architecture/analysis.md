# Analysis

- Topic: Career Agent 总体技术架构。
- Data type: 产品技术架构、功能展示、数据流转。
- Complexity: 中高，包含展示层、能力层、数据层和端到端流程。
- Audience: 大学生创新创业大赛评委、项目答辩听众。
- Tone: 专业、清晰、技术可信，但避免过度抽象。
- Language: zh。
- Recommended layout: structural-breakdown。
- Recommended style: technical-schematic。
- Aspect: 16:9 landscape。

## Visual Strategy

使用“分层架构 + 流程箭头”的结构表达：

1. 顶部放标题与副标题。
2. 中央主体分为三层：展示层、能力层、数据层。
3. 展示层用四张功能卡片，分别说明页面显示内容。
4. 能力层用技术组件标签，说明实现支撑。
5. 数据层用数据资产标签，说明流转结果。
6. 底部放端到端流程链路和一句总结。
