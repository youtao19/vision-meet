### 第 4 页｜用户痛点（与赛题一致）

**怎么填**

用 **四条** 呈现（与概要文档一致，便于评委对照赛题）：

1. **自我认知模糊**：兴趣、能力与岗位匹配关系不清，易跟风考研、考公、「进大厂」。  
2. **职业信息不对称**：行业信息来自社交媒体碎片，对新兴岗位真实技能与风险认知不足。  
3. **外部支持薄弱**：高校生涯课偏理论与技巧，师资与一线产业洞察不足；家庭引导两极化。  
4. **规划难落地**：缺少实习与项目验证，缺少可复盘的评估指标与动态调整方法。

**配图建议**

- **四象限图标**（每象限一个痛点关键词）或 **线性四步「问题链」示意图**。

**怎么填**

### 第 9 页｜大模型与智能体（Pi + AI 中枢）

**怎么填**

- **Pi Coding Agent**：任务型编排（`/api/v1/agent/tasks` 等），工具封装 **加载上下文、知识检索、创建匹配、生成报告** 等，由 Agent 决策调用顺序。  
- **AI 中枢 HTTP**：`/api/v2/ai/*`（润色、任务、简历 HTML 等）；报告 **AI 润色** 走 `POST /api/v2/ai/polish`。  
- **模型与配置**：默认 `kimi-coding/k2p5`；独立目录 `~/.career-agent/pi-agent`；架构上 **避免「双主链路裸 Chat Completions」**（见 `项目技术架构.md`）。  
- **简历多模态**：PDF/DOCX 文本提取；失败或图片简历时 **Pi 视觉解析** 回退（概要介绍）。

**配图建议**

- **Agent 工作流**：User → Task → Tools（search_knowledge / create_match / create_report）→ Summary。

### 第 10 页｜核心业务模块（画像 · 匹配 · 路径 · 报告）

**怎么填**

- **岗位画像**：`jobs-intelligence`、规范角色聚合；维度含 **专业技能、证书、创新/学习/抗压/沟通/实习** 等；前台 **岗位画像中心** 展示人工入库 **10 条** 计算机向画像（见 `实现跟踪.md`）。

- **生涯报告**：**七章节**；`career_path` 与行动计划；**模板化稳定输出**；编辑、版本、**PDF 导出**；报告与图谱 **同源逻辑**。
